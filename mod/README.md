# Futur mod Minecraft Java

Ce dossier réserve l'emplacement du futur mod Retrowave Challenger / Retro Action Verge. Il ne contient encore aucun code, dépendance ou configuration de build.

Avant toute initialisation, valider dans une Issue :

- le loader retenu (Fabric, NeoForge ou autre choix explicitement validé) ;
- la version Minecraft exacte et les versions des outils associés ;
- le périmètre client, serveur ou commun ;
- les responsabilités ajoutées au mod et les interfaces avec les packs ;
- les scénarios de tests et la distribution attendue.

Gradle et les fichiers du loader seront ajoutés après cette décision. Les fonctionnalités existantes restent dans leurs packs ; aucune extraction de gameplay n'est décidée par cette réservation.

Voir l'[architecture du dépôt](../docs/repository-architecture.md) et le [workflow](../docs/workflow.md).
